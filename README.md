# X-O Master Pro 🎮

لعبة تيك تاك تو (Tic-Tac-Toe) احترافية مبنية باستخدام تقنيات الويب الحديثة (HTML5, CSS3, JS, Bootstrap 5) مدعومة بسيرفر Node.js (Socket.io) للعب أونلاين. 

## المميزات ✨
- **10 مراحل متدرجة:** نظام خلايا مقفلة تفتح تدريجياً.
- **نظام النقاط:** كل مرحلة تعطي 10 نقاط (مجموع 100 نقطة للختم).
- **التخزين المحلي (LocalStorage):** لا يضيع تقدمك أبداً عند الخروج أو التحديث.
- **اللعب أونلاين:** إمكانية إنشاء غرفة بكود خاص والانضمام للعب مع الأصدقاء.
- **متجاوبة تماماً (Responsive):** تصميم يملأ الشاشة بدون اقتصاص، مع حث إجباري للعب بالوضع العمودي.
- **تأثيرات صوتية وبصرية:** احتفال (Confetti) عند ختم اللعبة وأصوات تفاعلية.
